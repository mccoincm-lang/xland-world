# Xland — xland.world

The Xland world: the 3D map, Hotex, passports, wallet, land, governance and the shared multiplayer API, served by one Cloudflare Worker (`xland-world`) with a D1 database.

## Layout

| Path | What it is |
|---|---|
| `src/index.html` | The whole page: world engine, game rules, economy, views. Edit here. |
| `src/atlas-ui.css` | The Atlas UI layer (design from the Lovable pass): type, brass panels, seals, emblem rows, passport. |
| `src/sprite.svg` | Hand-drawn emblems and ornaments as SVG symbols. Generated, do not edit by hand. |
| `src/worker.js` | The Worker: serves the page and the API (`/api/me`, `/api/sync`, `/api/doc`, `/api/lease`, `/api/waitlist`), the world economy (`/api/world`, `/api/quarx/*`, `/api/bux/sandbox`) and the Plaxa market (`/api/shop/open`, `/api/market/*`, `/api/coop*`), the server-held wallets (`/api/wallet`, `/api/wallet/import`, `/api/ledger`, `/api/farm/*`), construction timed by the server (`/api/builds`, `/api/build/*`), land bought in one server step (`/api/land/buy`), the living map (`/api/build/repair`, `/api/hazard/raise`, `/api/world/refresh`, and an hourly cron that reads real weather) and the Assembly held by the server (`/api/gov`, `/api/gov/propose`, `/api/gov/vote`). |
| `src/world.json` | The land registry (276 generated lots and the original parcels, with prices and what may be built), each territory's twin on Earth and the hazards. Shared by the page and the Worker; change only with both in mind. |
| `dist/index.html` | The page with the CSS, the sprite and `world.json` inlined. Generated by `node tools/build.mjs`; commit it with every change. |
| `tools/build-sprite.sh` | Regenerates `src/sprite.svg` from the approved React artwork in `../xland-territory-atlas`. |
| `test/dev-server.mjs` | Runs the Worker locally with SQLite standing in for D1. |
| `test/shots.cjs` | Screenshots every screen (phone and desktop, both themes) and runs the built-in rule tests. |
| `test/audit.cjs` | Visits every route as a new tester and reports errors, overflow, tiny text and broken artwork. |
| `test/journey.cjs` | Plays a new tester's first steps on a phone. |
| `test/r53.cjs` | API-only check of the r53 server rules: build sites (reserve, commit, cancel, complete, own plot) and the Assembly (residency, windows, revotes, timelock, law set). Needs the dev server. |
| `test/living-map.cjs` | API-only check of the r55 living map: paid land, the lot cap, buildings on lots, storm damage and repair, the weather bridge and heat on harvests. Needs the dev server (about two minutes). |
| `test/wallet-attacks.cjs` | 81 attack and failure scenarios against the server wallet, swaps, presale, the daily QuarX limit, alpha import, the order book, claims and the world timers; prints the gaps still open. Needs the dev server. |
| `test/map.cjs`, `test/economy.cjs`, `test/market.cjs`, `test/territories.cjs`, `test/coop.cjs`, `test/xahara.cjs` | Multi-citizen checks: shared land, server mining and BuX mint, a shop sale between citizens, a farm stand sale in FarmX and population stages, an Ixeland cooperative, a Xahara stall sale and resale, and the server wallet (forged credits refused, alpha carry-over). |

## Change, check, ship

```sh
node tools/build.mjs                 # always, after editing src/
node test/dev-server.mjs 8787        # open http://localhost:8787
node test/shots.cjs shots 8787       # optional: screenshots + rule tests
git commit -am "…" && git push       # Cloudflare builds and deploys main
```

The Worker also runs once an hour (`[triggers]` in `wrangler.toml`) to read the weather at each territory's twin from Open-Meteo; nothing to configure. Deploys keep the D1 data, the `ADMIN_KEY` secret and the xland.world domain. To undo a deploy: Cloudflare dashboard → Workers & Pages → xland-world → Deployments → roll back.
